# 1.17.0

WS-C3650-48FD-L/S/E now works in the device inspector and reports. A stack backup
that provisions the same-layout 48PD can use an operator-confirmed 48FD model
without losing its port settings. Exact inventory PID conflicts remain blocked.

- Adds 26 verified switch models: 14 standard 3650 variants, five 9300X bases,
  four compact Aruba CX models and three MikroTik models.
- Adds five compatible C9300X network-module choices, including a blank insert.
- Audits all current AOS-CX port-map IDs and exports a complete runtime-derived
  catalog: 279 switch/chassis choices, 75 module PIDs and 97 pending identities.
- Fixes selected-module port ordering when a sparse backup contains only later ports.
- Preserves separate stack-member details, fixed-versus-modular uplinks, complete
  VLAN reporting, workspace persistence and existing update behavior.

See [catalog sources, compatibility and limits](../CATALOG_REFRESH.md).
