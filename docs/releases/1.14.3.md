## Shared symbol key and optional workspace title

- Combined sheets now show one shared native VLAN, tagged VLAN, voice VLAN and LAG appearance key at the top rather than repeating it for each switch.
- Source configuration filenames are removed from switch headers; switch hostnames, models and member identities remain.
- **Name… → Use workspace name as report title (shared sheets)** enables an optional closet/location title. It is off by default and saved with the workspace. The saved workspace filename supplies the title; unsaved workspaces use switch identities. Custom output folder labels remain separate.
- The side VLAN-ID/color key, shared colors, readable pagination, PNG/PDF choices and standalone exports remain intact.
