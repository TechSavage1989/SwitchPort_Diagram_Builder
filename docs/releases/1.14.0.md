## Shared multi-switch sheets — correction to 1.13.0

- Switches from different configurations now appear together on the same A4 sheet in workspace order, not automatically one configuration per page. Readable complete switch blocks paginate only when necessary.
- Preview every combined sheet using the exact exported 300 DPI PNG; vector PDF diagrams and the combined full-inventory booklet use the same shared geometry. Selected/individual exports remain available.
- Workspace output folders use the saved workspace filename by default, support a custom label, and derive recognizable switch names when unsaved. Name collisions receive numeric suffixes without overwriting.
- One shared palette keeps matching VLAN ID/name combinations and matching normalized LAG labels consistent across combined and individual workspace exports. Conflicting or unnamed VLAN metadata remains distinct and is reported explicitly. Matching LAG colors do not imply physical links.
- Existing workspaces, configuration formats, vendor parsers, hardware layouts, model/device overrides, logos, clipboard/folder actions and updater integrity safeguards are preserved.

Dense chassis/stacks can require a dedicated A4 page rather than unreadable shrinking. Interactive native Windows dialogs and an actual user update/restart remain workstation checks; hosted CI covers Windows builds, native updater helpers and workspace-restoration regression tests.
