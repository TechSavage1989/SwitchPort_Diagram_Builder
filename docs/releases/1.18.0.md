# 1.18.0

Corrects physical port positions throughout the supported hardware profiles.

- Cisco 3650 uplinks now sit on the lower right, with proper copper bank gaps.
- Corrects single-row Cisco fiber bases, 9500 blank fascia, and Cisco network
  modules that previously appeared below their switch.
- Corrects MikroTik upper/lower numbering and the CRS309/317 Ethernet port side.
- Preserves Aruba/HPE bank gaps, blank panels, compact combo sockets, 3810 flex
  alignment, and side-by-side 2920 rear bays.
- Uses explicit geometry for Instant On 1930/1960 and existing catalog profiles.
- Adds finished-diagram regression checks for every selectable model, all 75
  module PIDs, and all ten parser-supported Instant On 1930 variants.

Dense reports retain complete VLAN details and proportional port shapes.
Read the [physical-position audit](../PHYSICAL_POSITION_AUDIT.md) for manufacturer
references, coverage and diagram conventions. Research-pending models remain
unavailable until their hardware is verified.
