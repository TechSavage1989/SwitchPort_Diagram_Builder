## Ordered multi-configuration workspaces

- Add multiple configuration files at once, including drag/drop; pasted text adds another item. Duplicate names remain independent.
- Drag to reorder or use keyboard-accessible up/down buttons. Selection and per-item device/model details follow the item.
- Explicit Save/Open workspace preserves ordered source snapshots and details in a separate versioned `.spworkspace.json` format. Treat these files as sensitive configuration backups.
- Build selected reports or export all items in order into collision-safe hostname/model folders. Failed items do not block the others.
- Optional combined PDFs keep each successful complete diagram on its own A4 page; the combined booklet retains full inventory pages.
- Selected output, clipboard copying and folder/chart actions remain independent from batch output.
- Existing vendor parsers, physical hardware layouts, report formats and updater integrity safeguards are retained.

Interactive Windows/WebView2 file-dialog and real user update/restart checks remain workstation verification steps; hosted CI validates the native build and updater helper.
