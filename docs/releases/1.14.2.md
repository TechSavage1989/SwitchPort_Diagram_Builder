## VLAN-ID colors, side key and PNG-first opening

- VLAN ID alone determines the shared color and key entry across configurations. Different names are retained as aliases; blank names no longer split identities.
- The combined VLAN key is beside the switches, not below them. Complete wrapped entries continue across A4 sheets when needed without tiny text.
- **Open chart** opens the latest project's PNG, including combined projects. **Open PDF** is a separate choice; **Sheets…** previews pages and **Open PNG** opens the displayed sheet.
- Latest-successful output, failed-build preservation, independent settings and LAG color rules remain intact.
- Existing consistent name-scoped color overrides migrate to ID-only keys; contradictory overrides are rejected explicitly so ordering never silently selects a winner.
