# 1.18.4

Adds automatic supplementary network-data detection when dragging files into the Switchport Diagram Builder workspace.

- Drop Auvik .xlsx reports, saved switch/firewall show-command output, and primary switch configuration backups together in one batch, in any file order.
- Recognize supplementary Auvik workbooks and operational CLI captures automatically, rather than treating them as unsupported switch configurations.
- Match a site-wide Auvik report to the corresponding already loaded configurations by device hostname, without mixing data from different devices.
- Route recognized CLI captures by the device's command prompt hostname when available. Otherwise use the explicitly targeted or selected switch, or require operator review when ambiguous.
- Allow supplementary file drops directly into the Supplementary data dialog, while rejecting a primary configuration there.
- Retain original single-configuration imports and MikroTik backup behavior, protect configuration-derived VLAN and port geometry, and preserve A4 reports and updater semantics.
- Add synthetic multi-device Auvik, mismatched/duplicate hostname, malformed input, mixed-batch and browser drag-and-drop regression coverage.

Supplementary observations are historical snapshots and are not proof of active links or authoritative switch configuration. Unmatched files are reported instead of silently being attached to a different device. Existing workspace saves remain compatible.

See docs/SUPPLEMENTARY_IMPORT.md for supported inputs, device association, limitations and security considerations. Actual interactive Windows/WebView2 startup and an installed updater restart still require workstation verification.
