# 1.18.3

Adds a supplementary network evidence importer to Switchport Diagram Builder.

- Attach Auvik .xlsx inventory reports and saved or pasted switch/firewall command output to the selected configuration.
- Read operational interfaces, IP addresses, routes, DHCP relays, LLDP/CDP neighbors, ARP and MAC forwarding data when recognized; retain other supported command lines as source-attributed reference observations.
- Match Auvik workbook records to the selected switch hostname, preventing unrelated site devices from being applied to its configuration.
- Preserve primary VLAN, LAG, module, port administration and physical-layout configuration. Supplemental information only fills otherwise unknown observed neighbor/status/speed fields.
- Save and reopen supplementary sources with the workspace. Export source-attributed supplementary-data.csv and supplementary-data.json plus a condensed technician summary.
- Add parsing, security, workspace and UI regression checks while retaining existing A4 diagrams and updater behavior.

Imported operational observations are snapshots, not confirmation of current cabling or an authoritative configuration. Confirm live interfaces and LLDP/CDP before production changes. Real interactive Windows/WebView2 updater behavior still requires workstation verification.

See docs/SUPPLEMENTARY_IMPORT.md for input coverage, device matching and limits.
