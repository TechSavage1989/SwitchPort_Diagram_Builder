# 1.18.5

Adds verified FortiGate 200G/201G FortiOS configuration support to Switchport Diagram Builder.

- Detect FortiGate 200G (FG2H0G) and 201G (FG2H1G) by their saved FortiOS configuration-version identifiers. Unknown FortiGate models remain blocked rather than being mapped onto an incorrect physical front panel.
- Render all **30 verified front-panel Ethernet sockets** in the correct faceplate bank order: dedicated HA and MGMT RJ45, eight GE RJ45 ports (port1-port8), eight 5GE RJ45 ports (port9-port16), eight 10GE SFP+ sockets (x1-x8), and four GE SFP sockets (port17-port20).
- Preserve per-port interface aliases, role, administrative status, configured speed and IP addresses. Label management "MG" inside the proportional RJ45 socket while retaining the full "mgmt" interface identity and description in exported details.
- Map configured 802.1Q VLAN subinterfaces to their physical parents and propagate aggregate VLAN membership to physical aggregate members. Do **not** invent a native/untagged VLAN for FortiGate routed ports.
- Include configured static routes and DHCP server interface references in the summary, and keep logical interfaces, tunnels, modem, console and USB out of the physical-port inventory.
- Add synthetic-only FortiOS parser, geometry, 30-port report and device-selection regression tests. Preserve previously supported switch platforms, A4 output and in-app updater behavior.

A saved firewall backup contains configuration snapshots, not confirmed current link state, physical cabling or live DHCP leases. Review exported reports before making production cabling changes. Protect imported backups and saved workspaces because they may contain encrypted credentials and infrastructure information.

The uploaded customer configuration was examined locally for interface structure; it and its secrets are **not** included in source, tests, screenshots or release artifacts.

Hardware geometry reference: Fortinet FortiGate 200G Series QuickStart Guide front panel, pages 8-9, and FortiGate 200G Series datasheet. See docs/FORTIOS_SUPPORT.md for supported fields and limitations.
