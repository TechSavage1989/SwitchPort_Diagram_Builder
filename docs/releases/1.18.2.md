# 1.18.2

Fixes shared-sheet generation for wide Cisco 3650 banks, including the
C9500 plus two-member 3650 workspace case.

- Tightens short bank gaps only as needed to fit the shared layout, retaining
  visible boundaries, full-size port shapes, numbering and blank fascia.
- Returns unused panel width to the side VLAN key before shortening detail
  columns, reducing unnecessary key continuation pages.
- Reserves room for the complete VLAN key heading and rejects truncation.
- Adds synthetic wide-bank, mixed Cisco, reorder and actual PDF regressions.

Individual reports and complete VLAN inventories retain their existing contents.
