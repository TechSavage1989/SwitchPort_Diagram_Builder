# Qualified Catalyst 3560-E configuration views

- Complete 48-port 3560-E backups can generate useful diagrams when their installed
  X2/TwinGig uplink modules are unknown, instead of stopping at a blanket hardware
  inventory block.
- Draw the 48 base RJ-45 ports separately from six clearly marked configured uplink
  alternatives. The upper bay relates Gi0/49 and Gi0/50 to Te0/1; the lower relates
  Gi0/51 and Gi0/52 to Te0/2. These are software alternatives, not six confirmed
  physical uplink sockets.
- Preserve every alternative's VLANs, voice settings, LAG membership, description
  and administrative state independently. PDF and CSV values remain complete.
- Diagram, UI, inventory and validation counts distinguish confirmed base ports
  from configured alternatives. Installed modules and active modes stay visibly
  unconfirmed. Exact WS-C3560E-48PD-SF model selection is also recognized.
- Keep genuine blocks for insufficient identity, conflicting model evidence,
  malformed syntax and invalid ranges. Existing 3650, 9500, Aruba and MikroTik
  physical-layout behavior remains.

Existing workspace, readable layout, shared palettes, report pagination, updater
and compile-time icon behavior remain. All required CI and publication checks gate
this release. Interactive native Windows UI/update restart remains workstation
validation.
